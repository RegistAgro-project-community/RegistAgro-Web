# RegistAgro-Web

RegistAgro Frontend

## Instalação necessária

Antes de começar, garanta que tenha instalado em sua máquina:

- Node.js && NPM

## Baixe o repositório

```bash
git clone https://github.com/RegistAgro-project-community/RegistAgro-Web.git
```

## Instale as dependências

```bash
npm install
```

## Arquivo .env

Vos enviarei pelo WhatsApp

## Principais comandos

```bash
npm run dev
```

```bash
npm run build
```

## JSON-SERVER

Deve ser executado na porta 8000

```bash
npx json-server --watch data/db.json --port 8000
```

## Acesse no navegador

**http://localhost:5173**

## Tecnologias

- React
- Vite

## Observação

Para o funcionamento completo da aplicação, certifique-se que o backend esteja rodando. ou utilizar o server online
