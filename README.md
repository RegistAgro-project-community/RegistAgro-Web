# RegistAgro-Web
RegistAgro Frontend

## Instalação necessária
Antes de começar, garanta que tenha instalado em sua máquina:
- Node.js && NPM

## Baixe o repositório
```bash
git clone https://github.com/RegistAgro-project-community/RegistAgro-Web.git
```

## Instale as dependências
```bash
npm install
```

## Arquivo .env
Vos enviarei pelo WhatsApp

## Principais comandos
```bash
npm run dev
```
```bash
npm run build
```

## Acesse no navegador
__http://localhost:5173__

## Tecnologias
- React
- Vite

## Observação
Para o funcionamento completo da aplicação, certifique-se que o backend esteja rodando. ou utilizar o server online
